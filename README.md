# Omkar Salunkhe: Portfolio

Static portfolio site (single `index.html`, no build step).

## Host on GitHub Pages
1. Create a new public repository on GitHub, e.g. `omkar-portfolio`.
2. Upload `index.html`, the `assets/` folder, `.nojekyll` and `README.md` to the repository root. Keep `assets/` next to `index.html` or the images and video will not load.
3. Go to Settings → Pages. Under "Build and deployment", set Source to "Deploy from a branch", Branch to `main`, folder `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-username>.github.io/omkar-portfolio/`.

Tip: name the repository `<your-username>.github.io` to get the shorter URL `https://<your-username>.github.io/`.

## Before going live
Images and the school film are already in `assets/`. The gallery has no empty tiles. The only yellow placeholders still in `index.html` are a few `[ADD …]` and `[REVIEW …]` notes inside the case studies.
